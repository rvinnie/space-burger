## Технологии

- React + TypeScript
- Redux + WebSocket
- Drag & Drop
- React Router
- JWT авторизация

## Основные функции

- **Конструктор бургеров** - drag & drop сборка бургеров из ингредиентов
- **Лента заказов** - отслеживание заказов в реальном времени через WebSocket
- **Личный кабинет** - история заказов и управление профилем
